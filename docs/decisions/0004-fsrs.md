# 0004 — FSRS v6 (ts-fsrs 6.0.0)

## Status
Accepted

## Context
Hanji is an Anki-style spaced repetition app. `packages/core` already depends on `ts-fsrs` 6.0.0, and the same FSRS code runs on the server (authoritative replay inside `/sync`) and on the client (offline-first computation), so both sides must use one version of the algorithm with identical results. The alternative was FSRS v7 (ts-fsrs 7.x), which adds a second memory trace, sub-day scheduling, and 34 optimizable parameters instead of FSRS v6's 21.

## Decision
Use FSRS v6 via `ts-fsrs` 6.0.0 as the scheduling algorithm in `@hanji/core`, rather than FSRS v7. The algorithm is shared between the API and the web app with a single version and identical imports.

## Rationale
- **Native integration and ecosystem support.** FSRS-6 is built into Anki 25.07+ and supported by AnkiDroid and AnkiMobile, so Hanji stays compatible with the Anki ecosystem without custom forks. FSRS-7 requires experimental builds or third-party implementations that can break syncing and add-on compatibility.
- **Lower review history requirements.** FSRS-6 optimizes 21 parameters and produces reliable personalized weights from roughly 1,000+ reviews. FSRS-7's 34 parameters need significantly more history to avoid overfitting to noise, which matters for a new app whose users start with little or no review data.
- **Near-identical long-term accuracy.** Hanji uses fixed learning steps (e.g. 10m 1d), so FSRS-7's sub-day interval prediction matters little. For standard multi-day spaced repetition, FSRS-6 performs virtually the same as FSRS-7.

## Consequences
- `ts-fsrs` stays pinned at `6.0.0` in `packages/core/package.json`; any move to v7 needs a new decision record and coordinated changes in `packages/core`, `apps/api`, and `apps/web`.
- FSRS-7's second-trace state and sub-day intervals are not supported; card states and intervals follow the FSRS-6 scheduling model.
- Parameter re-optimization runs on 21 weights, so it completes quickly on client and server hardware even with modest review histories.
